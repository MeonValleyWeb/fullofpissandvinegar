# Full of Piss and Vinegar

Bold, unapologetic, full of energy.

Built with Astro and deployed on Cloudflare Pages.

## 🚀 Development

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```

## 🌐 Deployment

Auto-deployed to Cloudflare Pages on every push to `feature/staging` branch.
